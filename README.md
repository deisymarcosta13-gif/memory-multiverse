# Memory Multiverse

Juego de memoria web desarrollado con React y TypeScript que consume la API de Rick and Morty para generar las cartas con personajes de la serie. Incluye tres niveles de dificultad, filtro de personajes por estado, cronómetro, contador de intentos y récords guardados en el navegador, con un diseño responsive pensado para jugar tanto en móvil como en escritorio.

**Stack:** React · TypeScript · Vite · Tailwind CSS · Rick and Morty API · localStorage

## Ejecutar en local

```bash
pnpm install
pnpm dev
```

Para generar la versión de producción:

```bash
pnpm build
pnpm preview
```
